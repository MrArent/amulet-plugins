## What is Amulet?

[**Amulet Map Editor**](https://www.amuletmc.com/) is a free, open-source Minecraft world editor supporting modern versions of both **Java** and **Bedrock** editions. It lets you edit worlds at the block level, run bulk operations, and convert worlds between editions and versions.

---

## Plugins

### Replace mc_hgd Blocks

> Replaces all blocks with the `mc_hgd` namespace *(Mounts of Mayhem: Dungeon Descent)* with appropriate filler blocks across an **entire world** — no selection required.

| Dimension | Replacement Block |
|:---------:|:-----------------:|
| Overworld | `minecraft:stone` |
| Nether | `minecraft:netherrack` |
| The End | `minecraft:end_stone` |

---

## Installation

1. Download the plugin file
2. Place it in your Amulet operations folder:
```
%localappdata%\AmuletTeam\AmuletMapEditor\plugins\operations\
```
3. Open Amulet and load your world
4. Go to the **Operation** tab, select the plugin, and click **Run**
